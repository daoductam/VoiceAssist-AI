# Trợ lý ảo đặt lịch / nhắc việc bằng giọng nói

> **Codename**: VoiceAssist AI
> **Platform**: iOS + Android (React Native / Expo)
> **Ngôn ngữ chính**: Tiếng Việt (mở rộng tiếng Anh sau)
> **Ngày tạo**: 2026-09-10
> **Tech Stack**: React Native (TypeScript), Expo, Zustand, expo-sqlite

---

## 1. Tổng quan

Ứng dụng mobile cho phép người dùng **đặt lịch hẹn, nhắc việc, tạo to-do, đặt báo thức, và hỏi đáp** hoàn toàn bằng **giọng nói tiếng Việt**. Hệ thống sử dụng chiến lược **AI Hybrid**:

- **Online**: Gọi API LLM bên ngoài (mặc định Groq, hỗ trợ OpenAI / Gemini) để xử lý ngôn ngữ tự nhiên chính xác và sáng tạo.
- **Offline**: Fallback sang **Rule-based NLU** (regex + keyword matching) cho các intent cơ bản. Các câu hỏi phức tạp được **queue lại** và xử lý khi có mạng.

Thông báo nhắc lịch được **tinh chỉnh ngôn ngữ tự nhiên** — không bao giờ "thô" — với hệ thống template đa dạng theo tone do user tự chọn.

## 3. Voice Pipeline

### 3.1 Luồng xử lý

```
User nói
   │
   ▼
[Speech-to-Text] ── @react-native-voice/voice (native engine)
   │                  Google Speech (Android) / Apple Speech (iOS)
   │                  Hỗ trợ tiếng Việt, không cần API key
   ▼
Transcribed Text
   │
   ▼
[Intent Parser] ── Online: Groq API structured output
   │                Offline: Rule-based regex tiếng Việt
   │
   ▼
Intent + Entities
   │
   ▼
[Action Router]
   ├── set_alarm      → AlarmService
   ├── set_reminder   → ReminderService
   ├── add_todo       → TodoService
   ├── query_schedule → CalendarService (query SQLite)
   ├── general_qa     → AI Chat (online) / Queue (offline)
   └── unknown        → Hỏi lại user
   │
   ▼
Action Result
   │
   ▼
[Response Generator] ── sinh câu phản hồi tự nhiên theo tone
   │
   ▼
[Text-to-Speech] ── expo-speech
   │                  Đọc phản hồi bằng giọng tiếng Việt
   ▼
User nghe
```

### 3.2 Speech-to-Text (STT)

- **Package**: `@react-native-voice/voice` (dùng native engine, hỗ trợ tiếng Việt `vi-VN`)
- **Trigger**: Nhấn giữ nút mic hoặc chạm để bật/tắt ghi âm
- **Xử lý**: Hiển thị realtime transcript trên UI khi user đang nói

### 3.3 Text-to-Speech (TTS)

- **Package**: `expo-speech`
- **Ngôn ngữ**: `vi-VN`
- **Cài đặt**: User có thể bật/tắt TTS, chỉnh tốc độ (rate: 0.5 - 2.0), chọn pitch và giọng đọc

## 4. Chiến lược AI Hybrid

### 4.1 Multi-provider Architecture

```typescript
export interface AIProvider {
  readonly name: string;
  processIntent(text: string, ctx: ConversationContext): Promise<AIResponse>;
  generateNaturalResponse(ctx: ReminderContext, tone: ToneStyle): Promise<string>;
}

export class GroqProvider implements AIProvider { /* Mặc định */ }
export class OpenAIProvider implements AIProvider { /* Tùy chọn */ }
export class GeminiProvider implements AIProvider { /* Tùy chọn */ }
export class OfflineProvider implements AIProvider { /* Fallback */ }

export class AIService {
  private onlineProvider: AIProvider;
  private offlineProvider: OfflineProvider;

  async process(text: string, ctx: ConversationContext): Promise<AIResponse> {
    if (await this.hasNetwork()) {
      try {
        return await this.onlineProvider.processIntent(text, ctx);
      } catch {
        return await this.offlineProvider.processIntent(text, ctx);
      }
    }
    return this.offlineProvider.processIntent(text, ctx);
  }
}
```

### 4.2 Online Mode

Gửi prompt structured cho LLM API:

```
System: Bạn là trợ lý ảo tiếng Việt. Phân tích câu nói của user và trả về JSON:
{
  "intent": "set_reminder|set_alarm|add_todo|query_schedule|general_qa",
  "entities": {
    "task": "string",
    "time": "ISO 8601",
    "date": "ISO 8601",
    "repeat": "daily|weekly|once",
    "priority": "high|medium|low"
  },
  "confidence": 0.0-1.0,
  "natural_response": "Câu phản hồi tự nhiên cho user"
}
User: "Nhắc tôi họp với sếp lúc 3 giờ chiều mai"
```

### 4.3 Offline Mode — Rule-based NLU

| Intent | Regex Patterns (tiếng Việt) | Entities trích xuất |
|---|---|---|
| `set_alarm` | `/(đặt\|cài\|tạo)\s*(báo thức\|chuông)\s*(lúc\|vào)?\s*(.+)/i` | `time` |
| `set_reminder` | `/(nhắc\|nhớ\|remind)\s*(tôi\|tui)?\s*(.+)\s*(lúc\|vào)\s*(.+)/i` | `task`, `time`, `date` |
| `add_todo` | `/(thêm\|ghi\|tạo)\s*(việc\|task\|công việc\|nhớ)\s*(.+)/i` | `task`, `priority` |
| `query_schedule` | `/(hôm nay\|ngày mai\|tuần này)\s*(có\|còn)?\s*(lịch\|việc\|gì)/i` | `timeRange` |
| `general_qa` | Không match intent nào → queue cho online | `question` |

**Xử lý thời gian tiếng Việt:**
- "3 giờ chiều" → 15:00
- "ngày mai" → tomorrow
- "thứ 2 tuần sau" → next Monday
- "cuối tuần" → Saturday-Sunday
- "8 rưỡi sáng" → 08:30

### 4.4 Offline Queue cho câu hỏi phức tạp

Khi offline gặp `general_qa`:
1. Lưu câu hỏi vào SQLite `PendingQuestions` table
2. Thông báo: *"Câu hỏi hay đó! Tôi sẽ trả lời khi có mạng nhé 😊"*
3. Khi có mạng → `ConnectivityService` trigger xử lý queue
4. Push notification kết quả cho user

## 5. Hệ thống nhắc lịch ngôn ngữ tự nhiên

### 5.1 Tone Settings

User chọn 1 trong 3 giọng điệu trong Settings:

| Tone ID | Tên hiển thị | Mô tả |
|---|---|---|
| `friendly` | Thân thiện | Như bạn bè, vui vẻ, gần gũi |
| `professional` | Chuyên nghiệp | Lịch sự, ngắn gọn, rõ ràng |
| `cute` | Dễ thương | Cute, có emoji, năng lượng tích cực |

### 5.2 Cơ chế sinh câu nhắc

```
Reminder đến hạn
       │
       ▼
┌─ Có mạng? ─┐
│ YES         │ NO
▼             ▼
Groq API      Template Engine
sinh câu      chọn random từ
tự nhiên      bộ mẫu đa dạng
theo tone     theo tone + context
│             │
▼             ▼
    TTS đọc + Push Notification
```

### 5.3 Online — LLM sinh câu

Prompt gửi API:
```
Viết 1 câu nhắc lịch ngắn gọn.
Tone: {friendly|professional|cute}
Sự kiện: {event_title}
Thời gian: còn {minutes} phút nữa
Thời điểm: {buổi sáng|trưa|chiều|tối}
Số việc hôm nay: {task_count}
Yêu cầu: tự nhiên, không thô, có cảm xúc phù hợp tone.
```

### 5.4 Offline — Template Engine

Mỗi tone có **15-20+ template**, chọn random để không lặp:

**Context variables:**
- `{event}` — tên sự kiện
- `{time}` — thời gian
- `{remaining}` — thời gian còn lại
- `{greeting}` — lời chào theo thời điểm (sáng/trưa/chiều/tối)
- `{task_count}` — số việc hôm nay

**Ví dụ template tone `friendly`:**
```
- "Ê, còn {remaining} nữa là {event} rồi đó!"
- "{greeting}! Nhớ {event} lúc {time} nha bạn!"
- "Sắp đến giờ {event} rồi nè, chuẩn bị đi!"
- "Hey, đừng quên {event} lúc {time} nhé!"
- "{greeting}, bạn có {event} sau {remaining} nữa thôi!"
```

**Ví dụ template tone `professional`:**
```
- "Nhắc nhở: {event} sẽ bắt đầu sau {remaining} nữa."
- "{greeting}. Bạn có {event} lúc {time}."
- "Lưu ý: {event} diễn ra sau {remaining}. Vui lòng chuẩn bị."
```

**Ví dụ template tone `cute`:**
```
- "Chủ nhân ơi, {event} sắp tới rồi nè 🌟"
- "Đến giờ {event} rồi á, fighting nha~ ✨"
- "{greeting} nè! Còn {remaining} nữa là {event}, go go! 🚀"
```

**Báo thức đặc biệt:**
```
- friendly: "Dậy thôi bạn ơi! Hôm nay bạn có {task_count} việc cần làm nè~"
- professional: "Chào buổi sáng. Hôm nay bạn có {task_count} công việc."
- cute: "Ohayo~ Dậy đi chủ nhân, {task_count} việc đang chờ nè! ☀️"
```

### 6.2 Firebase Firestore (cloud sync)

- Mirror các collection: `alarms`, `reminders`, `todos`
- Auth: Firebase Auth (Google Sign-in)
- Sync strategy: **local-first** — ghi SQLite trước, sync lên Firestore khi có mạng
- Conflict resolution: **last-write-wins** dựa trên `updated_at`

## 11. Yêu cầu phi chức năng

| Yêu cầu | Mục tiêu |
|---|---|
| **Offline-first** | App hoạt động 100% core features không cần mạng |
| **Thời gian phản hồi** | STT → Response < 2s (offline), < 4s (online) |
| **Battery** | Không chạy background service liên tục, dùng scheduled notifications |
| **Bảo mật** | API keys mã hóa bằng `expo-secure-store`, không hardcode |
| **Kích thước app** | < 35 MB (không có on-device LLM) |
| **Tương thích** | Android 8+ (API 26), iOS 14+ |
